# Recording a genuine product demo

After successfully running the app with your own API key, capture a 10–20 second screen recording that shows these authentic interactions:

1. Start a backend interview and answer the first question.
2. Show rubric feedback and a new follow-up that references a real weak spot.
3. Switch to System Design Lab, submit a prompt, and show a rendered Mermaid architecture.
4. Optionally run design review to reveal weighted feedback and heuristics.

Keep personal information, session IDs, and API keys off-screen. Record only actual results. Export a short GIF or MP4 to `assets/demo.gif` / `assets/demo.mp4` and embed it in the README under the intro. Do not label mock data as model-generated output.
